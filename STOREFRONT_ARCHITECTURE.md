# Ebook Storefront Architecture (2026 Standards)

## Mandatory UI Components
1.  **Hero Section:** Dynamic title and high-resolution cover preview (300 DPI).
2.  **Sample Reader:** A 5-page reflowable preview module built with React.
3.  **KDP Metadata Block:** Auto-populated from the `metadata.json` generated by the pipeline.
4.  **Buy Button:** Integrated with the Stripe MCP for instant checkout.

## Data Mapping
- `title` -> `<h1>`
- `description` -> `Description Section (HTML)`
- `keywords` -> `SEO Meta Tags`
- `genre` -> `Category Badge`

## Technical Constraints
- **Framework:** React 19+ / Next.js 15+.
- **CSS:** Tailwind CSS for responsive mobile-first design.
- **Compliance:** 100% WCAG 2.1 Accessibility compliance for screen readers.
